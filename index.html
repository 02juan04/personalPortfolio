Card Order Memorization Game

Card Order Memorization Game is a frontend application that challenges users to memorize and reconstruct a randomized deck of playing cards in correct order.

Users can generate a custom deck size (defaulting to a full 52-card deck) and enter a memorization phase where they can view cards either all at once or in smaller batches to improve recall.

In the recall phase, users must reconstruct the original order by placing cards into empty slots, receiving immediate feedback on correct and incorrect inputs.

The project focuses on state-driven UI rendering, user interaction flow, and game logic implementation using JavaScript.

Javascript • Vite • Tailwind CSS • Vercel

Live Foot Ball Stats

Live Football Stats is a frontend application that uses the API-Football service to display real-time data for leagues, teams, fixtures, and standings.

Users can select from multiple leagues, including the Premier League, Champions League, La Liga, and Liga MX, and view dynamically updated standings based on season selection.

The application features asynchronous data fetching from an external API, allowing match and league data to update dynamically without blocking the UI. It also includes a live matches section with real-time status indicators for ongoing and completed games.

Built with a focus on dynamic state-driven rendering, the interface updates automatically based on fetched data to reflect current match and league states.

NextJS • Tailwind CSS • api-football • Vercel

Task Tracker

Full-stack task management application built with React, Tailwind CSS, Supabase, and PostgreSQL.

Users can perform full CRUD operations (create, read, update, and delete tasks), with real time synchronization between the UI and database.

Features include task completion, archiving, and dynamic filtering across multiple views, implemented using reusable React components and asynchronous database requests.

React • Vite • Tailwind CSS • Supabase • Vercel • PostgreSQL
